# Implementation Plan: Extract User Module from Auth

**Branch**: `007-extract-the-user` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)

## Summary

Extract `com.ampairs.user.*` from the `auth` Gradle module into a new first-class `user` module. The two blocking coupling points are: (1) `UserDetailsWithId`/`UserDetailsWithRoles` interfaces defined inside `JwtService.kt` but imported by `User.kt` — resolved by moving them to `core`; (2) `auth` owning the `user` source tree — resolved by creating the `user` module and making `auth` depend on it. No functional changes; no API or schema changes.

## Implementation Steps

### Step 1 — Create `UserDetailsExtensions.kt` in `core`

Create `core/src/main/kotlin/com/ampairs/core/security/UserDetailsExtensions.kt`:

```kotlin
package com.ampairs.core.security

interface UserDetailsWithId {
    fun getId(): String
}

interface UserDetailsWithRoles {
    fun getRoles(): List<String>
}
```

Remove the same two interfaces from the bottom of `auth/src/main/kotlin/com/ampairs/auth/service/JwtService.kt` and add the import:
```kotlin
import com.ampairs.core.security.UserDetailsWithId
import com.ampairs.core.security.UserDetailsWithRoles
```

### Step 2 — Add `user` to `settings.gradle.kts`

```kotlin
include("user")
```
Place after `include("auth")` to reflect the logical dependency order.

### Step 4 — Move source files

Move all files from `auth/src/main/kotlin/com/ampairs/user/` to `user/src/main/kotlin/com/ampairs/user/` (same package paths, no package renames).

Update `User.kt` imports — change:
```kotlin
import com.ampairs.auth.service.UserDetailsWithId
import com.ampairs.auth.service.UserDetailsWithRoles
```
to:
```kotlin
import com.ampairs.core.security.UserDetailsWithId
import com.ampairs.core.security.UserDetailsWithRoles
```

### Step 5 — Move migration files

Move (not copy) these files from `auth/src/main/resources/db/migration/{dialect}/` to `user/src/main/resources/db/migration/{dialect}/` for both `mysql` and `postgresql` dialects:
- `V1.0.13__create_app_user_table.sql`
- `V1.0.15__add_firebase_uid_to_app_user.sql`
- `V1.0.16__add_user_deletion_fields.sql`
- `V1.0.23__add_profile_picture_fields.sql`

File content must not be modified.

### Step 6 — Update `auth/build.gradle.kts`

Replace:
```kotlin
api(project(":file"))
```
with:
```kotlin
api(project(":user"))
```

`file` is now a transitive dependency via `user`. Keep `api(project(":core"))` and `api(project(":notification"))` unchanged.

### Step 7 — Update `ampairs_service/build.gradle.kts`

Add to dependencies:
```kotlin

```

